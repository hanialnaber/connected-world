        03How I built it

        Eleven sources,
        one tested model.

        The hard part is not the charts. It is making 11 sources agree on what a country is, rebuilding ratings from raw results, and proving every number before it ships. The patterns are the ones I use on a production financial data platform.

        Rules that keep it honest.

        • Hold income fixed.Rich countries score higher on almost everything, so every link is also tested as a partial correlation controlling for GDP per person. Only links that survive are drawn.
        • Correct for testing 351 pairs.Benjamini-Hochberg false-discovery control (q < 0.01), at least 60 countries per link, countries under 500,000 people left out.
        • One country, one key.A 605-entry crosswalk maps football teams, Olympic codes, Eurovision names and historical birthplaces (“Prussia (Poland)”) to ISO codes. A test fails the build if coverage drops.
        • Count like the scorekeepers.A relay gold is one medal, not four; Youth Olympic events are excluded; only FIFA-recognised teams are rated, so regional sides never enter the Elo pool.
        • Latest, but not stale.Each country uses its latest value from 2015 onwards; projections in the source series are ignored.
